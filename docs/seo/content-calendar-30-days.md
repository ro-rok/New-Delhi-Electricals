# 30-Day Content & Authority Calendar

Prompt 4. Day 1 = the day the Prompt 4 batch is released to production.

This is **not** 30 articles. Five guides are already written and tested; the rest of the month is
spent making them count — links, outreach, measurement and one or two additions justified by
evidence. Publishing more than this in month one would mean writing faster than the SERP evidence
and the catalogue can support.

Effort is roughly 60% non-writing. That is deliberate.

## Standing rules

1. **No article ships to fill a slot.** Three calendar entries above are explicit go/no-go
   decisions, and "no" is a valid outcome that costs nothing.
2. **No guide publishes without a live commercial parent.** `npm run test:seo` enforces it.
3. **Verify prices before republishing.** Every catalogue figure in a guide is a promise.
4. **Do not report ranking or traffic gains before the data exists.** Search Console is still
   pending; see `gsc-data-required.md`.
5. **An `[EXPERT INPUT NEEDED]` marker is a work item, not a decoration.** Two are open, both
   scheduled in week 1.
